## Publishing
1. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
2. Enter custom domain www.vizcam.in.
3. In GoDaddy DNS for vizcam.in add four A records for @ pointing to:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
4. Add/edit www CNAME pointing to mec-osh.github.io, TTL 1 Hour.
5. Remove only conflicting website/parking DNS records, preserving MX, SPF, DKIM and DMARC email records.
6. After DNS verification, enable Enforce HTTPS in GitHub Pages.
7. Check site, links, navigation, and WhatsApp quotation form.
